## Claude Code notes

- Many students are new to the terminal. Before an action, say in one plain sentence what you are about to do; afterwards, name the file you wrote.
- Delegate to subagents by their exact name. If a required agent is missing, say which one and point to `handouts/function-cards.md`. Never do a missing agent's job yourself.
- Look at files with Read, Glob and Grep, not shell commands (`ls`, `cat`, `awk`): shell commands trigger approval prompts that confuse students.
- When a student asks you to build an agent, skill or panel, write files directly rather than using scripts or terminal commands — students' machines may lack Python or other tools.
- Keep chat replies short. The files hold the detail.
