# decisions/

Your team's design decisions — written by you, not by the agent (the agent is blocked from writing here).

One file per decision, e.g. `2026-11-20-sensing-method.md`:

- **Decision:** what you chose
- **Options considered:** what else was possible
- **Why:** the reasons, with links to reviews or source cards
- **We would revisit this if:** what new evidence would change your mind
