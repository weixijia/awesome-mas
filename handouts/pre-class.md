# Before class (about 20 minutes)

You need a paid Claude plan (Pro or higher). The free plan does not include Claude Code.

## 1. Install Claude Code

Open a terminal (Mac: **Terminal** app; Windows: **PowerShell**) and paste one line:

- **Mac / Linux:** `curl -fsSL https://claude.ai/install.sh | bash`
- **Windows (PowerShell):** `irm https://claude.ai/install.ps1 | iex`

Close the terminal, open a new one, and type `claude --version`. You should see a version number.
Problems? See https://code.claude.com/docs/en/troubleshoot-install — or bring your laptop 15 minutes early.

New to the terminal? https://code.claude.com/docs/en/terminal-guide

## 2. Open the starter

1. Download the starter: https://github.com/weixijia/thesis-mas-starter/archive/refs/heads/main.zip (no GitHub account needed), and unzip it somewhere easy, e.g. your Desktop. You get a folder called `thesis-mas-starter-main`.
   - Using git? `git clone https://github.com/weixijia/thesis-mas-starter.git` works too — or click **Use this template** on GitHub to get your own copy for your team.
2. In the terminal, go into the folder. The easiest way: type `cd ` (with a space), drag the folder into the terminal window, press Enter.
3. Type `claude` and press Enter. Log in when the browser opens.
4. When asked whether you trust this folder, choose **Yes**.
5. Type: `What is this folder for?` — if it explains the Thesis MAS, you're ready. Type `/exit`.

## 3. Do the M0 baseline

Follow `report/m0-baseline.md`. It takes 5 minutes, and you'll need it at the end of class.

## 4. Optional

Install [Obsidian](https://obsidian.md) and open the starter folder as a vault — it gives you a visual view of your knowledge base.
